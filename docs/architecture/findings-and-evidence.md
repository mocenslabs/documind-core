# Findings and Evidence

## Purpose

Findings make Repository Knowledge useful to an analysis purpose. Evidence makes knowledge and findings inspectable by connecting them to source material.

## Findings

A Finding is a scoped conclusion about the repository. It identifies its analysis purpose, the Knowledge Items it interprets, and relevant conditions or limitations. It can describe a characteristic, risk, gap, or notable relationship, but must not claim more than its support establishes.

A Finding is not evidence and must not become the only record of a repository fact.

## Evidence

Evidence references material in a Repository Snapshot. It identifies the supporting Source Artifact and Source Location, records the supported claim, and distinguishes direct observation from derived support when needed.

Multiple Evidence records may support one claim. Limited, conflicting, or missing support must remain visible to consumers.

## Relationship Model

1. A Repository Snapshot contains Source Artifacts and Source Locations.
2. Evidence references those locations.
3. Repository Knowledge records facts and relationships supported by evidence.
4. Findings interpret relevant knowledge for a declared purpose.

This direction makes a conclusion traceable to the repository state that justified it. Derived knowledge can be invalidated when its snapshot changes, and related findings can then be revised or withdrawn.
